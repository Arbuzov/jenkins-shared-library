# runLoopBackBuild

Declarative pipeline for building and publishing a Docker image for a LoopBack-based project.

The pipeline:

- Builds and pushes test images for change requests / non-master branches
- Builds and pushes production images for `master` (pushes `latest` and build tag) and tags the Git repo
- Runs `syft`/`grype` inspection and archives reports
- Publishes Confluence release notes and creates Jira versions based on configuration in `package.json`
- Handles cleanup of Jira/Confluence metadata when triggered by image deletion webhook (`GenericTrigger`)

## Usage

```groovy
runLoopBackBuild([:])
```

## Parameters

`arg` (Map) - currently unused by the implementation.

## Required project configuration

The pipeline reads `package.json` and expects (for release notes/Jira integration):

- `spacebridge.jira.project`
- `spacebridge.confluence.space`
- `spacebridge.confluence.notes` (parent page ID)

## Returns

No return value (defines and runs a Jenkins declarative pipeline).
