# getIDUversions

Fetches SIDU `.sit` artifacts from Nexus and returns a map `version -> full path`.

Artifacts are filtered by path prefix and recency (newer than `daysBack` days).

## Usage

```groovy
def artifacts = getIDUversions(
  daysBack   : 30,
  baseUrl    : 'https://nexus.asatnet.net/service/rest/v1/search/assets',
  repository : 'store',
  namePattern: '*.sit',
  pathPrefix : '/idu/sdk-s8000/ING/'
)
// artifacts['S8000-1.2.3-b45'] => '/idu/sdk-s8000/ING/2026-01-15/S8000-1.2.3-b45.sit'
```

## Parameters

All parameters are passed through a Map:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `baseUrl` | `'https://nexus.asatnet.net/service/rest/v1/search/assets'` | Nexus search API URL |
| `repository` | `'store'` | Nexus repository name |
| `namePattern` | `'*.sit'` | File name glob |
| `pathPrefix` | `'/idu/sdk-s8000/ING/'` | Path prefix filter |
| `daysBack` | `30` | Include artifacts newer than today minus this many days |

## Returns

Map where the key is artifact version (without `.sit`) and the value is the full Nexus path.
