# getNetboxDevices

Fetches a list of devices from NetBox via REST API.

## Usage

```groovy
def devices = getNetboxDevices(
  role: 'server',
  tenant: 'my-tenant',
  limit: 200
)
echo "Devices: ${devices.size()}"
```

## Parameters

All parameters are optional and passed through a Map:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `netboxUrl` | `'https://netbox.sandbox.asatnet.net/netbox'` | NetBox base URL; trailing slashes are dropped before `/api/...` is appended |
| `credentialsId` | `'netbox'` | Jenkins credentials ID containing the NetBox API token (Secret text) |
| `role` | `false` | Optional NetBox role filter |
| `tenant` | `false` | Optional NetBox tenant filter |
| `limit` | `500` | Result limit (single request) |

## TLS

The request is sent with `ignoreSslErrors: true`: several agents do not trust the Sandbox CA that
signs `*.sandbox.asatnet.net` yet, and the step may run on any of them inside a `node` block.

## Returns

List - NetBox response `results` array (devices).
